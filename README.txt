CAMERACAL GUIDE BUILDER V2

What this version adds:
- Brand/model/genre guide generation
- Premium dark and clean white themes
- Brand accent colours
- 12, 6 or 3 page starting guide options
- Editable text directly on the page
- Remove page buttons
- Add blank custom page button
- Built-in demo visual blocks
- Upload your own replacement image
- Recreated camera menu mock-up panels
- Browser print/save to PDF workflow

How to use:
1. Open index.html in a browser.
2. Choose brand, model, genre and theme.
3. Click Generate / Refresh Guide.
4. Edit text directly on the pages.
5. Upload images and click Use Upload on the image panel you want to replace.
6. Remove unwanted pages or add blank pages.
7. Use Print / Save as PDF.

Commercial note:
For final paid guides, replace demo blocks with your own photos, licensed stock images, AI-generated illustrative images, or your own photographed camera menu screens. Recreated menu mock-ups are safer than copying manufacturer manuals directly.
